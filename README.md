### QCM Anti-Cheat — Exam Platform
`Team project, ECE Paris · Apr 2026 · PHP 8, MySQL, JavaScript`

A secure online examination portal with role-based (admin/user) authentication, randomized question sets and automatic scoring. The JS anti-cheat layer detects tab switches, focus loss and fullscreen exit, blocks 9 keyboard shortcuts, and timestamps are synchronized server-side to prevent client-side tampering.

### Python Calculator — Secure Expression Evaluator
`Personal · Python 3.11+, Tkinter, ast, unittest`

A desktop calculator with the GUI cleanly separated from the calculation engine. Expressions are evaluated without `eval()` — parsed via `ast.parse()` against a whitelist of arithmetic operators — with full keyboard support, calculation history and error handling, backed by 38 automated `unittest` tests.
